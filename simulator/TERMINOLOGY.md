# English terminology reference

Reference: supplied 50:50 Senior–Subordinated Fund, Indicative Product Term Sheet, Version 5.0, 28 October 2026.

Senior / Subordinated identify the economic sides. UI terms use Net Invested Capital, Upfront Management Fee, Return Allocation Basis, Excess Profit, Accrued Carry, Carry Reversal, and Annualised Return.

The uploaded draft describes Carry accruing at 8% or above. The calculator retains the previously instructed strictly-above-8% trigger. This change localizes language only; it does not alter the calculation convention.
